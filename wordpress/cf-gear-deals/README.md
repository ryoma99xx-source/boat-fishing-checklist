# Cutlassfish Gear Deals

楽天・Yahoo!の釣具（年1回の高額品）を毎日記録し、**実質価格が直近90日の実質最安＋本体価格の3%以内**に入った日だけ、サイト下部にバナーを出してSNSに流すWordPressプラグイン。外部DBは使わず、WordPressのMySQLに専用テーブルを作ります。

## セットアップ

1. `cf-gear-deals` フォルダを `wp-content/plugins/` に置いて有効化
2. 管理画面「釣具の買い時 → 設定」で入力
   - 楽天：アプリID・アクセスキー（2026年の新API）・アフィリエイトID。アプリの「WebサイトURL」はこのサイトのURLにする
   - Yahoo!：Client ID・バリューコマースのアフィリエイトID
3. 「商品」に1行1品番（右/左・ギア比・竿のタイプごと）で登録
   ```
   機種 | スラッグ | 品番名 | JAN | 検索語 | タグ | 追加店舗
   ```
   - 機種が同じ品番は、通知とバナーで1つにまとめる
   - JANが空欄なら、検索語でYahoo!を検索して自動で埋める（末尾に `?` が付くので、確認して消す）。`!スプール` のように頭に!を付けた語は除外
   - タグは記事のタグ・カテゴリ名と合わせると、そのページで関連商品のバナーが優先される
   - 取り扱いのない店舗は3回連続で見つからないと休止し、7日に1回だけ確認し直す
4. 「店舗を探す」で店舗名（かめや、マルニシ…）を並べて実行すると、登録済みJANを実際に売っている店舗の楽天ショップコード・Yahoo!ストアIDが一覧になる。チェックして「共通店舗に設定」（送料別の店舗は、設定画面で `code=550` のように追記）
5. 「キャンペーン」で初期ルールを確認（楽天カードSPU・ワンダフルデーは無効で入っています）
6. 「状況 → 今すぐ全部実行」で動作確認

## 自動実行

WP-Cronで1日2回。アクセスに依存しないよう、サーバーのcronから実行するのがおすすめです。

```
# wp-config.php に define('DISABLE_WP_CRON', true); を入れた上で
5 6,18 * * *  cd /path/to/wp && wp cfgd run
```

## 毎日の流れ

1. **カレンダー取得**：Yahoo!ボーナスカレンダー（公式・倍率と上限込み）→ 計算に使う施策として保存。楽天カレンダー（ユーザー投稿）→ 「予想」として保存し、メールで通知。告知を確認したら管理画面で倍率と上限を入れて「計算に使う」に変更
2. **楽天の店舗トップ**：共通店舗のトップページを未ログインで1日1回読み、ショップ全体の倍率（「通常商品10倍」）、クーポンの見出し（円OFF・%OFF。LINE友だち・モバイル・アプリ限定は無視）、「単価100円以上を3商品同時購入でさらに10倍（上限3,000pt）」型の企画を反映。クーポンは条件が読めないので「条件未確認」として扱い、計算に入れるかは設定で切り替え
3. **価格取得**：商品×店舗ごとに本体価格・送料・ポイント倍率・在庫
4. **判定**：クーポン → ストアポイント → 施策（上限で円の頭打ち）→ Yahoo!合計48.5%上限 の順に実質価格を計算し、直近90日と比較。記録が14日に満たない商品は判定しない
5. **通知**：買い時の商品をバナーに表示し、`cfgd_deal_found` アクションを発火（同じ商品は7日間再通知しない、SNSは1日1件まで）。異常（取得失敗、ページ構造の変化、楽天の新しい予定）はメールで通知

## SNS連携（Buffer）

このプラグインはBufferへ直接は投稿しません。既存の Cutlassfish Buffer Publisher 側で次のアクションを受けて投稿してください。

```php
add_action( 'cfgd_deal_found', function ( array $deal, string $text ) {
	// $text … 投稿本文（#PR 入り）
	// $deal['best']['url'] … アフィリエイトURL
	// $deal['best']['eff_price'], ['points'], ['lines'] … カード画像用の数字と内訳
}, 10, 2 );
```

## 紹介ページ

固定ページに `[cfgd_calendar days="21"]` を置くと、今後3週間のお得日（確定・予想・対象ストア限定）が日付順に出ます。

## スマホからクーポンを登録する（iPhoneショートカット）

商品ページを見ていてクーポンを見つけたら、共有メニューから登録できます。ログイン情報はサーバーに置きません。

**事前に**：管理画面「設定 → スマホからクーポン登録」に表示される**合言葉**と**送り先URL**（`https://サイト/wp-json/cfgd/v1/coupon`）を控える。

**ショートカットの作り方**（ショートカットアプリ →「＋」）
1. 名前を「釣具クーポン登録」に。下部の ⓘ →「共有シートに表示」をオン、受け取る種類は「URL」と「Safari Webページ」だけにする
2. 「入力を要求」：質問「割引（例：5% / 1000）」
3. 「メニューから選択」：「この商品だけ」「店舗全体」。それぞれの中に「テキスト」で `item` / `store` を置き、メニューの後ろで結果を変数「範囲」に設定
4. 「入力を要求」：質問「期限（例：10/16 0:00。空欄なら今日いっぱい）」。「入力なしを許可」にする
5. 「URLの内容を取得」
   - URL：送り先URL
   - 方法：POST
   - ヘッダー：`X-CFGD-Token` ＝ 合言葉
   - 本文：JSON
     - `url` ＝ ショートカットの入力
     - `discount` ＝ 2の入力結果
     - `scope` ＝ 範囲
     - `until` ＝ 4の入力結果
6. 「辞書の値を取得」でキー `message` → 「通知を表示」

**使い方**：商品ページで共有 →「釣具クーポン登録」→ 割引・範囲・期限を入れる。通知に「Yahoo! casting（この商品）に5%OFFを登録しました。期限 10/15 23:59」と出れば完了。登録と同時に今日の判定をやり直します（SNS通知はしない）。

- Yahoo!・楽天アプリの共有で出る短縮URL（yahoo.jp など）は、サーバー側で元のURLに戻して判定します
- 「10/16 0:00まで」は10/15いっぱいとして扱います
- 「この商品だけ」にすると、その商品の出品にだけクーポンを使って計算します
- 合言葉が漏れたら、設定画面の「合言葉を作り直す」で無効にできます

## Yahoo!直営アフィリエイトのリンクを登録する（iPhoneショートカット）

Yahoo!ショッピングアフィリエイト（直営）はバリューコマースより料率が高いので、Yahoo!側のリンクは直営を優先します。直営リンクは商品ごとにアプリで発行する方式で自動では作れないため、一度だけ発行して登録します。

**ショートカットの作り方**
1. 名前を「直営リンク登録」に。ⓘ →「共有シートに表示」をオン、受け取る種類は「URL」
2. 「URLの内容を取得」
   - URL：`https://サイト/wp-json/cfgd/v1/afflink`
   - 方法：POST
   - ヘッダー：`X-CFGD-Token` ＝ 合言葉
   - 本文：JSON、`url` ＝ ショートカットの入力
3. 「辞書の値を取得」でキー `message` → 「通知を表示」

**使い方**
1. 管理画面「商品」タブの下にある **Yahoo!直営アフィリエイトのリンク** の表で、未登録の行の「商品ページを開く」をスマホで開く
2. Yahoo!ショッピングアプリの「共有」で直営リンクを発行 → 共有先で「直営リンク登録」を選ぶ
3. 通知に「直営リンクを登録しました：casting / 4550133652738」と出れば完了

- 未登録の出品が買い時になったときは、バリューコマースのリンクで投稿し、メールで「この商品ページで直営リンクを発行して」と知らせます
- 優先度は、よく最安になるキャスティング・ポイントのYahoo!店からがおすすめです
