# ドラゴンカウンター：テンヤカタログの月1回更新

## 流れ

1. **ChatGPT**：下の「ChatGPT への指示」で、新商品と状態の変化を調べ、【カタログ追加】の JSON を出す
2. **オーナー**：その JSON を台帳の司令塔（または Claude）に貼って「カタログに追加して」と送る
3. **Claude Code**：`python3 sites/dragon-counter/tools/catalog_add.py <json>` で確認 → `--write` で書き込み → commit・push（自動で公開）

## 守ること（個人のデータを消さないため）

- カタログは**足すだけ**。すでにあるテンヤの メーカー・製品名・号数・カラー の表記は**絶対に変えない・消さない**
  （アプリは所有テンヤをこの4つから作った ID で覚えているため、表記を変えると所有テンヤから見えなくなる）
- 発売された・生産終了になった などの「状態」だけは、表記を変えずに `status` で更新できる
- 追加スクリプトが、すでにあるものを飛ばし、表記の間違い・抜けをエラーにする（ChatGPT の出力をそのまま信用しない）
- 個人の所有テンヤ・個数・当日のリスト・自分で追加したテンヤ・釣行の記録は各スマホの中にあり、カタログ更新では変わらない
- 念のための守り：アプリは所有・リスト・記録で使ったテンヤの名前を各スマホに控えている。万一カタログ側で表記が変わったり外れたりしても、控えから表示し「カタログから外れました」と出る

## ChatGPT への指示（そのまま貼る）

```
あなたは、船のタチウオ釣り用「テンヤ」のカタログ係です。毎月1回、ドラゴンカウンター（https://dragon-counter.cutlassfish.tokyo/）のテンヤカタログに足す分を調べてください。

## 1. 今のカタログを読む
https://dragon-counter.cutlassfish.tokyo/catalog-all.txt を開いて、今入っているテンヤ（メーカー｜製品名｜号数｜カラー｜状態、1行1件）を全部読む。読めない場合は同じ内容の https://dragon-counter.cutlassfish.tokyo/catalog-all.json か、オーナーが添付するファイルを使う。
照合はオーナー側のプログラムでも行うので、カタログにあるか迷うものは「new」に入れてよい（既にあるものは自動で飛ばされる）。

## 2. 調べる
各メーカーの公式サイト（製品ページ・新製品ニュース）で、船のタチウオ用テンヤを調べる。
対象メーカー（m にはこの表記を使う）：DAIWA / SHIMANO / JACKALL / HAYABUSA / OWNER / Major Craft / PRO MARINE / START / YAMASHITA / DUO / がまかつ / マルシン漁具
- 新しい製品、または既存製品の新しい号数・新しいカラーで、カタログに無いもの → 「new」に入れる
- カタログにあるものの状態が変わった（発売予定 → 発売、生産終了 など）→ 「status」に入れる
- 公式サイトで確認できないものは入れない（ショップの情報やうわさだけのものは入れない）。推測で埋めない

## 3. 書き方のルール（大事）
- カタログにすでにあるテンヤは、m・p・z・c を catalog-all.json の表記と1文字も変えずに使う。表記の直し・削除はしない
- 新しく足すテンヤの p（製品名）は、同じ製品がカタログにあればその表記に合わせる。無ければメーカー公式の製品名どおり
- c（カラー）はメーカー公式のカラー名どおり。号数ごとに1行（30号と40号があれば2行）
- z は数字だけ（例：40）
- s（状態）は次のどれか："" / "発売予定" / "限定色" / "生産終了・在庫のみ" / "売り切れあり"
- h は替えヘッド（ヘッドだけの商品）なら true、それ以外は false
- u はその製品のメーカー公式ページの URL（https://…）

## 4. 出力
最後に、次の形の JSON だけを ```json のコードブロックで出す。足すものが無ければ new・status を空の配列にする。

【カタログ追加】
{"checked":"YYYY-MM-DD",
 "new":[{"m":"DAIWA","p":"製品名","u":"https://…","h":false,"z":40,"c":"カラー名","s":""}],
 "status":[{"m":"DAIWA","p":"製品名","z":40,"c":"カラー名","s":""}]}

JSON の後に、調べたメーカーと、見つけた新商品・状態の変化を日本語で3〜5行にまとめる。
```
