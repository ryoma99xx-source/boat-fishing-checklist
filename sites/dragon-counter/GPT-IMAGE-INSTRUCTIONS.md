# 指示書：カタログ用の商品写真を切り抜く（ChatGPT 用）

ドラゴンカウンター（テンヤ）・ティップランカウンター（エギ・シンカー）・タイラバカウンター（ヘッド・ネクタイ・スカート）のカタログに載せる、色ごとの小さな商品写真を作る作業です。
この文書をそのまま ChatGPT に渡し、元の写真（ファイルかURL）と一覧表を添えて頼んでください。見本は `GPT-IMAGE-SAMPLES.png`。

---

## 1. 絶対に守ること（オーナーの決まり）

- **写真は「切り抜く」と「縮小する」だけ**。それ以外は一切しない。
  - 色の補正・明るさ・コントラスト・シャープ・ノイズ除去をしない
  - 背景を消す・塗る・描き足す・形を直す・傷を消す・文字を消すをしない
  - 傾きを直す（回転）もしない
- **画像生成・画像編集の AI 機能（DALL·E など）は使わない**。新しい画像を作らない。
  作業は **Python（コード実行）で、Pillow の crop と resize だけ**で行う。
- 写真は **メーカー公式の色別写真**を使う。無い色だけ、大手釣具店の色別商品写真を使ってよい。どこから取ったか（URL）を必ず記録する。
- **取り違えに注意**。製品・色の名前と写真が合っているか、1枚ずつ目で確かめる。自信がない写真は使わず「写真なし」にする。
- 透明な背景（PNG）は、透明のまま残す。

## 2. 切り方

見本（`GPT-IMAGE-SAMPLES.png`）を見てください。左が元の写真で、赤い枠が切る範囲。右ができあがり。

1. **商品の周りで切る**：白い背景（または透明）でない部分を、ぐるっと囲む四角で切る。
   - 「白い背景」＝ RGB のいちばん小さい値が 236 以上の点。透明＝アルファ 128 未満。
   - 1〜2ピクセルの点やゴミ・細い枠線は無視する（数ピクセル内側で判定してよい）。
   - 四角の外側に **6ピクセルだけ余白**を残す（写真の端を越えない）。
2. **文字・ロゴ・別の写真が入っているとき（見本の例3）**：いちばん大きい商品の塊（エギなら本体＋カンナ）だけを囲む。
   ロゴ、「赤テープ」などの札、「イメージ」の文字、発光時の小さな写真は、枠の外に出す。
   商品にかかっている文字は消さない（それなら、その写真は使わない）。
3. **輪郭がとれないとき**（白い商品が白い背景、商品が2本写っているなど）：背景を消したりせず、その写真の中で商品が入る四角を手で決めて、そのまま切る。どの四角にしたか（x0, y0, x1, y1）を記録する。
4. **縮小**：縦横比を変えずに、次の大きさの中に収まるよう縮小する（拡大はしない）。

| 種類 | 最大の大きさ（横×縦 px） | 形式 |
|---|---|---|
| エギ（ティップラン） | 320 × 140 | WebP（品質82） |
| シンカー | 360 × 270 | WebP（品質82） |
| テンヤ | 240 × 180 | WebP（品質82） |
| タイラバのヘッド・ネクタイ・スカート | 320 × 240 | WebP（品質82） |

Python の例（これ以外の処理を足さないこと）：

```python
from PIL import Image
im = Image.open(path)                      # 透明があれば RGBA のまま
im = im.crop((x0, y0, x1, y1))             # 2. で決めた四角
im.thumbnail((MAXW, MAXH), Image.LANCZOS)  # 縮小だけ
im.save(out, 'WEBP', quality=82, method=6)
```

## 3. 返してほしいもの

1. **切った写真**：ファイル名は `メーカー_製品_色.webp`（記号は `-` に置き換えてよい）。zip にまとめる。
2. **一覧表（CSV）**：1行に1枚。

| 列 | 内容 |
|---|---|
| maker | メーカー名（カタログの表記どおり） |
| series | 製品名（カタログの表記どおり） |
| color | 色名（カタログの表記どおり。製品全体の写真は空欄） |
| file | 返した写真のファイル名 |
| image_url | 元の写真のURL |
| source | 取った場所（メーカー公式／店の名前） |
| crop | 手で決めた四角（x0,y0,x1,y1）。自動で切ったときは空欄 |
| note | 気になったこと（例：色名が公式と少し違う、写真なし） |

3. **確認シート**：切った写真を、色名を下に書いて並べた1枚の画像（目で取り違えを確かめるため）。
4. **写真が見つからなかった色の一覧**。

## 4. してはいけないことの例

- 背景をきれいな白に塗り直す → ×
- 写真が暗いので明るくする → ×
- ロゴが商品にかかっているので消す → ×（その写真は使わない）
- 写真がないので、似た色の写真を使い回す／AIで作る → ×（「写真なし」にする）
- 切った写真を拡大して大きくする → ×
